# Cookie Manager

**The modern, open source cookie management tool for Chrome.** View, edit, export, and protect your browser cookies with a clean, intuitive interface.

Looking for an EditThisCookie replacement? Cookie Manager picks up where EditThisCookie left off -- with a modern Manifest V3 architecture, better security, and full open source transparency.

## Why Cookie Manager?

Web developers, QA engineers, and privacy-conscious users need reliable access to browser cookies. Whether you are debugging authentication, testing cookie-based features, or managing your privacy, Cookie Manager gives you full control.

After EditThisCookie stopped working with Chrome's Manifest V3 transition, many users were left without a capable cookie editor. Cookie Manager was built from the ground up for Manifest V3, ensuring long-term compatibility and security.

---

## Key Features

- **View all cookies** -- See every cookie for the current site with full details (name, value, domain, path, expiration, flags)
- **Edit cookies** -- Modify any cookie attribute directly from the popup
- **Add new cookies** -- Create cookies with full control over every field
- **Delete cookies** -- Remove individual cookies or clear all cookies for a domain
- **Export and import** -- Export cookies as JSON for backup, migration, or testing
- **Cookie search** -- Quickly find cookies by name across all domains
- **Cookie profiles** -- Save and restore sets of cookies for different testing scenarios
- **Cookie health monitor** -- See security flags and potential issues at a glance
- **Cookie rules** -- Set up automatic rules for cookie management
- **Multilingual** -- Available in English, Spanish, French, German, Japanese, and Portuguese

## Frequently Asked Questions

### Is Cookie Manager a good EditThisCookie replacement?
Yes. Cookie Manager was built specifically to provide the same core functionality that EditThisCookie users relied on, using Chrome's modern Manifest V3 architecture. It includes cookie viewing, editing, adding, deleting, and exporting.

### Can I export and import cookies between browsers?
Yes. Cookie Manager exports cookies as standard JSON files that can be imported back into any Chrome instance with Cookie Manager installed.

### Does Cookie Manager work with HttpOnly cookies?
Yes. The Chrome extensions API provides access to HttpOnly cookies, and Cookie Manager fully supports viewing and editing them.

### Will Cookie Manager work after Manifest V2 is deprecated?
Yes. Cookie Manager is built entirely on Manifest V3, which is Chrome's current and future extension platform. It will continue to work as Chrome phases out older extension formats.

### Is my cookie data safe with this extension?
Cookie Manager processes all data locally in your browser. It never sends cookie data to any server. The full source code is open for inspection.
