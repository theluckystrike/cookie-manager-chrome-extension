# Changelog

All notable changes to Cookie Manager will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-17

### Added

- View, edit, create, and delete cookies for any website
- Search and filter cookies by name, value, or domain
- Export cookies as JSON or Netscape format
- Cookie profiles: save and restore cookie sets for switching environments
- Auto-delete rules: schedule automatic cookie cleanup per domain
- Cookie health dashboard: security analysis with scores and recommendations
- JWT token decoder: detect and decode JWT cookies inline
- Domain protection: prevent accidental modification of important cookies
- Read-only mode: browse cookies without risk of changes
- Context menu integration: clear or export cookies from any page
- Dark mode support (follows system preference)
- Internationalization: English, Spanish, French, German, Japanese, Portuguese
- Keyboard shortcuts for power users
- Accessibility: WCAG 2.1 compliant with screen reader support
